Single purpose
Translate web pages, selected text, PDF documents and supported video subtitles, with original and translated text available for comparison.

storage
Store translation settings, provider preferences and local application data in the user's browser.

tabs
Identify the active tab for translation actions and open extension pages such as settings, PDF translation and the translation center.

alarms
Schedule local configuration backups and periodic cleanup of translation caches and local data.

cookies
Observe authentication-cookie changes on configured service domains to invalidate cached authentication state and keep hosted-service status consistent with sign-in changes.

contextMenus
Provide translation actions for selected text through the browser context menu.

scripting
Inject the translation interface and required scripts into pages or frames when the user invokes translation.

webNavigation
Track navigation and frames to maintain translation state, update the extension icon and inject translation support into the appropriate page frames.

offscreen
Use a local offscreen document for text-to-speech audio playback.

sidePanel
Currently opens the extension's coming-soon side panel. Translation functionality is provided through the popup, in-page interface and dedicated extension pages. This placeholder is not promoted as a working translation feature.

Host permissions (*://*/*)
Read user-selected text and page content, insert translated text into the original page, handle supported video subtitles and contact the translation endpoint chosen by the user. Translation can be used on arbitrary websites.

Remote code
JavaScript and WebAssembly executables are packaged with the extension. The remotely downloaded PDF layout model is an ONNX data file. It is cached for layout inference.
