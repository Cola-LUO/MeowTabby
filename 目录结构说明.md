# MeowTabby 目录结构说明

本文档说明 MeowTabby（基于 read-frog 模板的浏览器翻译扩展）各文件夹的作用，帮助刚接触项目的你快速定位代码。

> 技术栈：WXT 框架 + React 19 + TypeScript + Tailwind。扩展入口由 `src/entrypoints/` 决定，构建后产物在 `.output/`（不进 git）。

---

## 一、根目录关键文件

| 文件/目录                                                 | 作用                                                              |
| --------------------------------------------------------- | ----------------------------------------------------------------- |
| `src/`                                                    | **核心源码**（所有功能代码都在这）                                |
| `public/`                                                 | 静态资源，构建时原样拷贝进扩展（如扩展图标 `public/icon/*.png`）  |
| `assets/`                                                 | 项目宣传/文档用素材（banner、demo gif、商店图等），**不进扩展包** |
| `readmes/`                                                | 多语言版 README（es/ja/ko/ru/tr/vi/zh-CN/zh-TW）                  |
| `scripts/`                                                | 开发辅助脚本（如抓取 AI SDK 模型列表、调试用的 touch 脚本）       |
| `wxt.config.ts`                                           | WXT 构建配置（manifest 声明、权限、入口、dev server 端口等）      |
| `package.json`                                            | 依赖与脚本（`dev:edge` / `build:edge` 等）                        |
| `tsconfig.json` / `vitest.config.ts`                      | TypeScript 配置 / 测试配置                                        |
| `pnpm-workspace.yaml` / `pnpm-lock.yaml`                  | pnpm 工作区与依赖锁                                               |
| `components.json` / `postcss.config.cjs`                  | shadcn/ui 配置 / Tailwind PostCSS 配置                            |
| `测试指南.md`                                             | 本地运行与加载扩展的步骤（见同目录）                              |
| `AGENTS.md` / `CONTRIBUTING.md` / `SOURCE_CODE_REVIEW.md` | 贡献者指南、代码审查说明                                          |

## 二、`src/` 源码结构

```
src/
├── entrypoints/   扩展的所有"入口"（popup、background、各 content script、选项页等）
├── components/    可复用的 React 组件（UI 积木）
├── utils/         工具函数与业务逻辑（最多文件，594 个 .ts）
├── hooks/         React hooks（状态/副作用封装）
├── env/           环境变量校验（dev/prod 必填项）
├── locales/       国际化文案（9 种语言 .yml）
├── types/         TypeScript 类型定义
└── assets/        源码内引用的图标/样式（svg、png、css）
```

### 2.1 `src/entrypoints/` — 扩展入口（最重要）

WXT 按此目录下的子目录/文件自动生成 manifest 对应项。每个子目录是一个独立入口：

| 入口目录                  | 对应扩展能力                             | 界面/作用                                         |
| ------------------------- | ---------------------------------------- | ------------------------------------------------- |
| `popup/`                  | 点击扩展图标弹出的小窗口                 | 快捷翻译、主交互入口                              |
| `sidepanel/`              | 侧边栏面板                               | 常驻翻译/阅读面板                                 |
| `options/`                | 选项页（`chrome://extensions` 里"选项"） | 完整设置（最大子目录，205 文件）                  |
| `background/`             | 后台 service worker（42 个 .ts）         | 常驻逻辑、消息中枢、定时任务、跨页面通信          |
| `translation-hub/`        | 翻译中枢页                               | 集中处理翻译请求的页面                            |
| `offscreen/`              | 离屏页面                                 | 在 MV3 下执行不能直接在 SW 跑的任务（如音频/TTS） |
| `host.content/`           | **宿主 content script**                  | 注入普通网页，处理划词/选中翻译                   |
| `selection.content/`      | 选中文本 content script                  | 处理用户选中文字的浮层                            |
| `side.content/`           | 侧边 content script                      | 网页侧边的翻译 UI                                 |
| `guide.content/`          | 引导 content script                      | 新用户引导浮层                                    |
| `input-injector.content/` | 输入框注入                               | 在页面输入框注入翻译功能                          |
| `interceptor.content/`    | 拦截器 content script                    | 拦截特定页面行为                                  |
| `subtitles.content/`      | 字幕 content script                      | 视频字幕翻译                                      |
| `partner-bridge.content/` | 合作方桥接                               | 与外部站点通信的桥                                |

> 命名规则：`*.content` 后缀 = content script（注入网页）；其余是独立页面或后台。

### 2.2 `src/components/` — 复用组件

| 子目录/文件            | 作用                                                                   |
| ---------------------- | ---------------------------------------------------------------------- |
| `ui/`                  | 基础 UI 组件库（基于 shadcn/base-ui，51 个 tsx：按钮、对话框、下拉等） |
| `translation/`         | 翻译相关专用组件                                                       |
| `llm-providers/`       | LLM 服务商相关组件                                                     |
| `providers/`           | React Context 提供者（全局状态注入）                                   |
| `badges/`              | 徽章（如套餐等级 PlanBadge）                                           |
| `form/`                | 表单组件                                                               |
| `icons/`               | 图标组件                                                               |
| `prompt-configurator/` | Prompt 配置器 UI                                                       |
| `user-account-menu/`   | 用户账户菜单（含头像逻辑，引用 `assets/icons/avatars/guest.svg`）      |
| `recovery/`            | 数据恢复 UI                                                            |
| 其余散件（`.tsx`）     | 各功能小组件：语言选择框、快捷键录制、加载动画、Markdown 渲染等        |

### 2.3 `src/utils/` — 业务逻辑与工具（最大目录）

按功能分子目录，重点：

| 子目录                                                                                            | 作用                                                                                                                        |
| ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `config/`                                                                                         | 配置相关的核心逻辑（244 文件，最大子目录）                                                                                  |
| `host/`                                                                                           | 宿主页面（划词翻译）逻辑（85 文件）                                                                                         |
| `subtitles/`                                                                                      | 字幕翻译逻辑（41 文件）                                                                                                     |
| `ai/`                                                                                             | AI/翻译请求封装                                                                                                             |
| `providers/`                                                                                      | 各 LLM 服务商适配（20 文件）                                                                                                |
| `atoms/`                                                                                          | Jotai 原子状态（12 文件）                                                                                                   |
| `db/`                                                                                             | 本地数据库（Dexie/IndexedDB）                                                                                               |
| `tts-playback/`                                                                                   | 文本转语音播放                                                                                                              |
| `content-script/` `content/` `dom/`                                                               | 网页 DOM 操作、content script 辅助                                                                                          |
| `i18n/`                                                                                           | 国际化运行时加载                                                                                                            |
| `auth/` `google-drive/` `hosted-ai/` `notebase/` `orpc/` `server/` `session-cache/` `site-rules/` | 认证、云盘、托管 AI、笔记库、RPC、服务端、会话缓存、站点规则                                                                |
| 根级 `.ts` 文件                                                                                   | 通用工具：`http.ts`(请求)、`logger.ts`(日志)、`message.ts`(通信)、`theme.ts`(主题)、`url.ts`、`hash.ts`、`navigation.ts` 等 |

### 2.4 其他 `src` 子目录

| 目录       | 作用                                                                                                         |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| `hooks/`   | React hooks：`use-text-to-speech`、`use-google-drive-auth`、`use-debounced-value` 等（11 个 .ts + 1 .tsx）   |
| `env/`     | 环境变量 schema 与校验（`index.ts` / `shared.ts`），定义 dev/prod 必填项                                     |
| `locales/` | 国际化文案源文件（en/es/ja/ko/ru/tr/vi/zh-CN/zh-TW 共 9 种 .yml）                                            |
| `types/`   | 全局类型：`config/`（22 文件配置类型）、`translation-state`、`tts-playback`、`edge-tts`、`content`、`dom` 等 |
| `assets/`  | 源码内部用的图标/样式（svg、png、css），不同于根 `assets/`（宣传图）                                         |

## 四、新手建议的查看顺序

1. 先看 `wxt.config.ts` 了解扩展声明了哪些权限与入口。
2. 再看 `src/entrypoints/popup/` 和 `src/entrypoints/options/` 理解主界面。
3. 翻译核心逻辑从 `src/utils/host/` 和 `src/utils/config/` 入手。
4. 改 UI 找 `src/components/ui/` 和对应功能组件。
5. 想加语言/改文案看 `src/locales/`。
