📋 方案 A 改动清单

只需改 MeowTabby/src/assets/styles/theme.css（:root + .dark）和 host-theme.css —— **零 TSX 改动**

/* theme.css :root */
--rf-brand: oklch(53% 0.14 62); /* 从 76% 0.124 82° 改 */
--rf-brand-foreground: oklch(1 0 0); /* 从 0.985 改（纯白，对比度更高）*/
--rf-chart-1..5: hue 62° 阶梯 /* 从 hue 82° 改 */
--rf-ring: oklch(70% 0.14 62); /* 可选，从冷灰 286° 染橙 */

/* theme.css .dark —— 同样改 brand 和 brand-foreground */
--rf-brand: oklch(53% 0.14 62); /* 亮暗共用 */
--rf-brand-foreground: oklch(1 0 0); /* 深橙 + 白字，暗下仍可读 */

/* host-theme.css（content script 独立覆盖）*/
--read-frog-brand: oklch(53% 0.14 62); /* 输入翻译 spinner 用 */
不动的： accent-blue（Switch track / checkbox / dashed "add" / link）、中性色整套（primary / secondary / muted / border / ring 冷灰）、sidebar 全套、chart 数据结构。
