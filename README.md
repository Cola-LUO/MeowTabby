# MeowTabby

基于 [read-frog](https://github.com/mengxi-ream/read-frog) 的浏览器翻译扩展的二次开发版本。

## 项目简介

MeowTabby 衍生于开源项目 **read-frog**，在原作的基础上做了**界面优化**与**交互逻辑**的改进，并正在**并行开发其它功能**。功能更新会第一时间开源出来。
